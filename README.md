# VueJSLabs2026

Лабораторні роботи з Vue.js 3.

| Лабораторна | Тема | Папка |
| --- | --- | --- |
| Lab 1 | Знайомство з Vue.js 3 (Composition API), To-Do застосунок | [lab1](lab1/README.md) |
| Lab 2 | Адмін-панель: компоненти, props/emits, provide/inject, слоти, Vue Router | [lab2](lab2/vue-project/README.md) |
| Lab 3 | Стилізація компонентів: scoped, CSS Modules, теми, Transition | [lab3](lab3/vue-project/README.md) |
| Lab 4 | Управління станом (Pinia) та локалізація (vue-i18n) | [lab4](lab4/vue-project/README.md) |

## Запуск

Кожна лабораторна - окремий Vite-проєкт:

```sh
npm install
npm run dev
```
